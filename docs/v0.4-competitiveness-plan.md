# agentic-mail v0.4 竞争力提升计划

> 目标：在初赛（10/4）与复赛（10/9）窗口内，通过差异化 UI 与 AI 功能，建立相对 VibeMail 的独特竞争优势。

---

## 一、差异化定位：从"邮件客户端"到"邮件行动平台"

### 1.1 竞争格局再审视

| 维度 | VibeMail | agentic-mail（我们） |
|------|----------|----------------------|
| **核心叙事** | 精美邮件客户端 + AI 辅助 | 邮件行动平台 + 宿主服务贡献 |
| **UI 风格** | 三栏传统布局、森林墨水主题 | 智能卡片流、任务驱动视图 |
| **AI 定位** | 摘要 + 起草（辅助型） | 分类 + 行动建议 + 规则授权（决策型） |
| **平台贡献** | 使用 Mail Host Service | 既用又建，反哺生态 |

### 1.2 我们的独特价值主张

**"不只是读邮件，而是让邮件驱动行动"**

- **VibeMail** 解决"如何更优雅地读邮件"
- **agentic-mail** 解决"如何从邮件中快速采取行动"

### 3.1 AI 功能：智能分类（1 天）

**目标**：自动识别邮件类型（订单、账单、通知、社交、垃圾）

#### 3.1.1 分类规则

```rust
enum MailCategory {
    Order,      // 订单、物流、发货
    Bill,       // 账单、还款、缴费
    Notification, // 系统通知、安全提醒
    Social,     // 社交、好友、邀请
    Newsletter, // 订阅、新闻、营销
    Spam,       // 垃圾邮件
    Normal,     // 普通邮件
}

fn classify(from: &str, subject: &str, body: &str) -> MailCategory {
    // 关键词匹配
    if subject.contains("订单") || subject.contains("发货") || body.contains("物流") {
        MailCategory::Order
    } else if subject.contains("账单") || subject.contains("还款") || body.contains("缴费") {
        MailCategory::Bill
    } else if from.contains("noreply") || from.contains("no-reply") {
        MailCategory::Notification
    } else {
        MailCategory::Normal
    }
}
```

### 3.2 AI 功能：行动建议（1.5 天）

**目标**：根据邮件内容，建议下一步行动

#### 3.2.1 行动类型

```rust
enum MailAction {
    TrackOrder(String),      // 查看物流（附链接）
    PayBill(String),         // 立即还款（附链接）
    Reply(String),           // 回复邮件（附草稿）
    Archive,                 // 归档
    Delete,                  // 删除
    None,
}

fn suggest_action(category: MailCategory, body: &str) -> MailAction {
    match category {
        MailCategory::Order => {
            if let Some(tracking_url) = extract_tracking_url(body) {
                MailAction::TrackOrder(tracking_url)
            } else {
                MailAction::None
            }
        }
        MailCategory::Bill => {
            if let Some(payment_url) = extract_payment_url(body) {
                MailAction::PayBill(payment_url)
            } else {
                MailAction::None
            }
        }
        _ => MailAction::None,
    }
}
```
