## Phase 1: UI 打磨（优先级最高）

### 1.1 收件箱列表

| 改动 | 说明 |
|---|---|
| 未读圆点 | 左侧 avatar 旁加蓝色圆点（is_read == false） |
| Badge 位置 | 移到 subject 行右侧，与时间同行或 subject 下方 |
| 分隔线 | 左对齐 avatar 中心（margin-left: 72），当前已实现 |
| 选中态 | 点击后背景微变（hover/pressed 反馈） |
| 空状态 | 优化"暂无邮件"提示文案和图标 |

### 1.2 邮件阅读器

| 改动 | 说明 |
|---|---|

| 返回按钮 | "‹ 收件箱" 改为更清晰的导航样式 |

### 1.3 回复撰写页

| 改动 | 说明 |

| 正文编辑区 | 增大高度，优化边框和焦点态 |
| 发送按钮 | 顶部右侧，醒目主色调 |

### 1.4 行动卡片

| 改动 | 说明 |
|---|---|

## 技术约束提醒

- OctoScript 64ms 入口预算：单回调不串联重活
- 字符串方法有限：无 find/slice/lower/upper，用 split 替代
- regex 捕获组多字节 panic：用 split 取上下文窗口
- hub stamp 必须在 bundle 改动后、check/card-host 前执行
- Windows card-host 实测可用（D3D11）
